Projects by Alaura Ward

Things I've built, things I'm building, and things I'm still figuring out.

1. NASA Student Launch Initiative

I'm working with MSU Denver's NASA Student Launch team on a multidisciplinary rocketry project that brings together design, manufacturing, electronics, testing, safety, and industry collaboration. I'm especially interested in the hardware and software side of the project, like sensors, cameras, circuits, and using code to help a system recognize or sort what it detects.

Skills: Aerospace • Engineering Design • Electronics • Coding • Teamwork

2. Technical Drawing + AutoCAD

I'm learning how to take a 3D part and turn it into an accurate 2D engineering drawing using AutoCAD. I've worked with orthographic views, projection lines, the miter line method, hidden lines, centerlines, dimensions, and other drafting tools. I actually really enjoy CAD because it feels like solving a visual puzzle while also figuring out how a part would actually be built.

Skills: AutoCAD • Technical Drawing • CAD • Orthographic Projection

3. Portfolio Website

I built this website using HTML, CSS, Bootstrap, Git, and GitHub as a place to document what I'm learning and the projects I'm working on. I wanted it to feel like me instead of just being a basic school portfolio, so I've been working on making it responsive, accessible, and actually interesting to look through.

Skills: HTML • CSS • Bootstrap • Git • GitHub • Responsive Design

4. AIAA Fly-Off Competition 2027

I'm planning to compete in the 2027 AIAA Fly-Off as another way to get more hands-on aerospace and aviation experience. I'm excited to work through the full engineering process from designing and building to testing, breaking things, fixing them, and figuring out why something did or didn't work. I'll keep updating this project as the competition gets closer.

Skills: Aerospace • Prototyping • Testing • Engineering Design • Teamwork

5. PC Building + Family IT

A lot of my first hands-on experience with computers came from building, upgrading, and troubleshooting PCs for myself and my family. I've worked with CPUs, GPUs, RAM, storage, cooling, power supplies, BIOS settings, drivers, and Windows while trying to figure out why something suddenly decided it didn't want to work. It's honestly one of the things that made me realize I like understanding how hardware and software work together.

Skills: PC Hardware • Troubleshooting • Windows • BIOS • Hardware/Software Integration

Working as an F1 Technician gives me hands-on experience troubleshooting technology, maintaining equipment, and solving problems in a fast-paced environment.
